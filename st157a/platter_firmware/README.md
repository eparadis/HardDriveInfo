Note! The files in this directory are completely created using an LLM.

The binary files are correct - they are made from concatenating valid
sectors cross-checked with more than one capture pass.

The disassemblies, however, are essentially speculative.

Improved disassembly listings would be very helpful! Please submit a
pull request with improvements if you can.

Another key piece of missing evidence is the mask ROM contents of
of any of the drives in the ST-1xxA or ST-1xxN series. If you have
a copy of the contents of mask ROM of any of these drives, please
get in contact via Github.
